      networkTest {
          compileClasspath += sourceSets.main.output
          runtimeClasspath += sourceSets.main.output

      networkTestImplementation.extendsFrom implementation
      networkTestCompileOnly.extendsFrom compileOnly
      networkTestRuntimeOnly.extendsFrom localRuntime

  neoForge.mods.getByName(project.mod_id).sourceSet(sourceSets.networkTest)

          sourceSet = sourceSets.networkTest
          gameDirectory = layout.buildDirectory.dir('network-acceptance/client')

          systemProperty 'farmupcraft.networkAcceptanceRoot',

  Stage 1 is acknowledged only after observing that balance on the actual client.

  real new ClientLevel, new player/probe database object identities, same balance,
  production resync marker, and absence of the poisoned old cache entry.
* Server sends ONE production DataBaseFullS2C with 24 independently deterministic
  60,000-byte ASCII rows. It measures the exact encoded payload >1MiB. The source
  is a detached, non-broadcasting snapshot using the real server registries, NOT a
  fake world/transport. No large entries are incrementally sent. Stage 3 requires
  all 24 exact strings in the real client cache, old marker removal, and a matching
  digest acknowledged over a real C2S NeoForge payload.
* Server records four verified receipts then disconnects the client. A LOWEST
  LoggingOut listener checks production cache clearing using the SAME prior real
  level, avoiding the false positive of level-change-induced clearing. The client
  writes its final PASS only after both previous databases are replaced and empty.
